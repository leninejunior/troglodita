# /troglodita

Ativa o modo de compressão de tokens em PT-BR.

## Uso

```
/troglodita          # nível total (padrão)
/troglodita leve     # sem muletas, frases completas
/troglodita total    # telegrafia + imperativo
/troglodita máximo   # abreviações, setas, mínimo absoluto
```

## Desativar

Dizer "parar troglodita" ou "modo normal".
